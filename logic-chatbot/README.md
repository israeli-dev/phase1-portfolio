# Nigerian Food Suggestion Chatbot

A beginner-friendly Python project that started as a simple rule-based chatbot and is gradually evolving into a food recommendation application focused mainly on Nigerian meals.

The application interacts with the user, asks what meal period they are interested in, and randomly recommends a food together with its ingredients and recipe information.

This project is part of my Phase 1 Python learning portfolio, where I am deliberately building the same project progressively—from basic Python programming to more advanced software and AI concepts.

 Project Goal

The goal of this project is to build a simple conversational food recommendation system that can:

Ask the user what they want to eat.
Accept choices such as Breakfast, Lunch, or Dinner.
Randomly recommend a suitable meal.
Display the ingredients required.
Provide recipe/preparation information.
Handle invalid user input without crashing.

The project will become more sophisticated as I improve my Python and software engineering skills.
